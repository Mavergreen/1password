## Linux 1Password (Porthole preset)

A Porthole preset for 1Password: install Porthole first, then this. Its postinstall materializes a
native "Linux 1Password.app" on your Mac, and it installs the `op` CLI (item management, lock/unlock,
SSH agent, browser wiring). Versioned for the 1Password release it tracks (`<version>-mavericks.N`).
